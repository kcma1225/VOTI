# Demo／測試資料

**全部是合成資料。** 不代表真實台灣語者，也不能當作研究語料或人工 gold 標準。

## 產生方式（macOS）

```bash
.venv/bin/python scripts/make_demo.py data/demo-fixture
```

- 音訊：用 macOS 內建的 `say -v Meijia`（系統中文語音）唸一段固定文字，再用 FFmpeg 轉成 16 kHz mono WAV。
- 字幕：在音訊長度的一半處切成兩個 cue，產生 SRT。時間界線是自動算出來的，**刻意不準**，用來練習邊界修正。
- 輸出目錄裡會附一份 README，註明以上限制。目錄已存在時腳本會中止，不會覆蓋。
- 授權：由本機系統語音即時生成，只供本機測試用，不要再散布。

非 macOS 環境：使用任何自己有權使用的短音訊，自行寫一份 SRT 即可。單元測試（`tests/`）則是用 FFmpeg 的 `sine` 產生器即時生成音訊，不需要外部檔案。

## 單元測試資料

`tests/` 會在臨時目錄裡產生正弦波 WAV 和手寫 SRT/VTT，涵蓋重疊、捲動字幕、空白、時間錯誤、越界等情況。語者向量測試使用**明確標示的受控向量**，只存在測試用的暫存資料庫中，用來驗證相似度、分群與人工覆寫邏輯。這些不是模型輸出。

真實 ECAPA 模型只對 demo fixture 實際執行過一次（見 PROJECT_STATUS.md）。
